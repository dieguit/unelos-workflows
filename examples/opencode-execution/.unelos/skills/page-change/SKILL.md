---
name: page-change
description: Keep a small page change grounded in agreed requirements and project constraints.
---

Read applicable project instructions before touching the page. Use the existing
components and styles; do not edit vendor components, broaden scope or add a UI
dependency for a copy/layout adjustment. Record a reproducible acceptance check.
Honor project-required frontend, review and browser tools; report unavailable
requirements rather than claiming verification. Keep responsive behavior and
accessibility intact. Read existing outputs, preserve useful sections and update
the same paths. Persist decisions needed downstream in the Task report. Workers
report changed paths/evidence to the controller and never edit its ledger.
