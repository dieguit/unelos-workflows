# Council deliberation

1. Read question.md for the question, context, constraints and success criteria.
2. Inspect relevant code read-only; never run shell commands or delegate.
3. Answer independently from your role focus in your supplied report:
   - `## Answer`
   - `## Reasoning` with `path:line` references
   - `## Assumptions`
   - `## Confidence`: high|medium|low, with why
   - `## Uncertainties`
4. If unable to answer, still finish your report with
   `## Status: could not answer` and the reason.
