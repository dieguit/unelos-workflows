Use the installed Unelos controller protocol. Arguments: $ARGUMENTS
Obtain current work through next --json; never infer progression from ledger prose.
Without a running run, present numbered workflows and Continue without Unelos
(/unelos off) as the last numbered option; accept a number or Workflow name.
Wait for explicit selection, even if there is one workflow. Do not auto-start.
With an existing run, recover current state and report it. This command does not
authorize Task work or progression. Honor the user's latest instructions; read
the ledger brief and reports without dispatching, writing, completing, deciding
a gate, starting or renaming. Wait for explicit authorization to resume work.
The native plugin, not this template's text, establishes controller activation.
